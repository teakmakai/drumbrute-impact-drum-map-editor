DrumBrute Impact — Drum Map Editor

A faster, scale-aware replacement for the Drum Map page in Arturia MIDI Control Center. Reads your Impact, lets you edit all pad notes, and writes them back to the DrumBrute itself.
Before you start: close MIDI Control Center, FL Studio and anything else using MIDI (only one app can open the Impact's MIDI port). Use Chrome or Edge. The browser will ask permission for "MIDI devices with SysEx" — click Allow. This only ever writes the 19 drum-map note values; it backs up what's on the device before you send anything.

#InstrumentNoteColor-variant note
Click a note cell, then click a key below. Choosing a root or scale lays out the scale automatically: Kick gets the root, the other pads climb the scale in order, and the color variants carry on up from there, so no two sounds share a note. Yellow = changed but not sent yet. Red wavy underline = note shared with another sound. Note names match MIDI Control Center (note 0 = C-2, so 60 = C3).

Keyboard orange = root · bright = in scale · dim = out of scale · numbers = instruments (purple = color variant)

4 · Send to Impact

Impact clock: not seen
"Next beat / bar" follows the MIDI clock the Impact sends while it plays (4/4) and writes the new notes just before the beat or bar, so a key change lands cleanly on the downbeat. With no clock coming in, changes go out immediately. The Impact can't switch a pad's MIDI output off, so M (mute) moves that send to the note chosen above. Pick a note nothing in your DAW or synth responds to (C-2 is usually safe), and unmuting puts the real note back.
